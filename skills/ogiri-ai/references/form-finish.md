# 形式条件の仕上げ

ここへ来る前に確定した通常の5本を固定する。切り口の再設定や、5本全体の再生成はしない。

1. 内容を言葉で述べる代わりに、回答そのものの成り立ちで求められた内容を実演する追加候補を、別に3本作る。同じ操作の言い換えだけで埋めず、実演の仕方を変える。追加候補では、別の出来事や能力を申告せず、出題者の指定への応じ方そのものに求められた性質を出す。お題の形式条件を1つ外すこと自体に、その内容を示す意味があるかを試す。
2. この追加候補に限り、文字列として目の前で実演される行為も足切りの「絵」として扱う。内容との接続・共感・1点ズラしは引き続き点検する。発話を状況描写へ変えず、20文字以内と他の条件は守る。
3. 外れを条件どおりに直すと実演が消えるか確かめる。外れの意味に解説が要る候補、単なる拒否や数え間違い、無関係な内容を求めるお題にも同じ文のまま通る候補は捨てる。自分の表記について何かを述べているなら、実際の本文と一致していることも数えて確かめる。
   実数との一致は正確さの検査であり、内容の成立や面白さの根拠ではない。違反の事実や字数を報告するだけで、お題が求める内容を実演していない候補も捨てる。
4. 残った追加候補のうち最も強い1本を、固定した5本のうち最も弱い1本だけと比べる。実演型の高さは、実行の不可能さではなく、お題が作った期待からの落差で判定する。現実に実行できるという理由だけで弱にしない。「落差の大きさ×回収の鮮やかさ」で勝り、残る4本と同じオチ構造でもなければ、その1本だけを差し替える。ほかの4本は一字も変えない。負けた場合や判定に迷う場合は、元の5本をそのまま使う。例外の採用ノルマはない。
5. 差し替えた場合は、外した形式条件が1つだけか、本文の字数・文字種・自己申告をもう一度点検する。20文字上限や他の条件は免除しない。不整合があれば追加候補を直すか元の5本へ戻し、ほかの4本は一字も変えない。例外は5本中最大1本。確定した本文をそのまま元の出力フォーマットで5本だけ出す。
